## 从 2000 年起的完整逐日状态还没有得到

- HOSE 当前上市公司公告接口在 2000—2005 年返回总数 0，2006 年只有 2 条，最早为 2006-04-05。这是该接口的覆盖情况，不能推出所有历史档案不存在。
- Vietstock 在 2000—2006 年有 80 个月份返回 HTTP 200 空正文，没有总数。空响应也可能是上游失败，因此保留为覆盖未知，不能填成零事件或正常状态。
- 监管记录从 2009 年起较丰富，但不同状态的起点不同，仍不能承诺之后每一天完整。
- 71 个事件的市场标签为 UPCOM，日期却早于其成立；131 个警示类事件的标题提到“控制”。这些是待复核项，不能直接按分类写成历史事实。

UPCOM 启用日为 2009-06-24，更早的市场归属需核验。[HNX 2009 年报](https://owa.hnx.vn/ftp/PORTALNEW/PUBLICFACTBOOK_FA/20161220/HNX_Bao%20cao%20thuong%20nien_2009.pdf)

公告发布日期、生效日、撤销日分别保存。Vietstock 的 `Time` 与 `DateOrder` 也不能合并：同一退市/转板事件可能在最后交易和重新上市的两个月都被匹配。本次 250 个跨月重复事件的内容一致，已按事件 ID 去重并保留原始分区。

### 早期档案已经实际补到 2004—2005 年

证监会旧站可匿名正常访问。curl 需要普通会话 Cookie 才能避免重定向循环，不需要登录、关闭 TLS 校验或浏览器私有接口。

从正式停牌通知及后续市场报告核实 BTC 的三次状态变化：

| 变化 | 生效日 | 官方证据 |
| --- | --- | --- |
| 临时停牌 | 2005-04-11 | [SSC 正式通知，页面日期 2005-04-08](https://ssc.gov.vn/webcenter/portal/ubck/pages_r/l/chitit?dDocName=APPSSCGOVVN162065577) |
| 恢复交易 | 2005-04-13 | [SSC 2005-04-18 市场报告](https://ssc.gov.vn/webcenter/portal/ubck/pages_r/l/chitit?dDocName=APPSSCGOVVN162065431) |
| 加上警示标记 | 2005-04-13 | 同上，解除条件为满足盈利的上市条件；解除日期未知 |

人工核实的事实保存在 `ssc_verified_events.json`，原文和收据保留。这些事实不在现代日历的上述最早起点内，说明现代接口为空不能证明早期没有状态数据。

旧站 2004 年、关键词 `giao dịch` 检索共 101 条，六页得到 101 个唯一链接，正文全部下载成功；该检索的最早页面日期为 2004-09-27。[2004 年上市许可撤销原文](https://ssc.gov.vn/webcenter/portal/ubck/pages_r/l/chitit?dDocName=APPSSCGOVVN162065451)记载企业没有及时办理上市手续，属于上市许可事件，不能直接写成已上市股票退市。

同一关键词在 2000 年、2001—2003 年分别检索为 0 条；这只证明该关键词检索的结果。尚未拿到这四年的完整股票状态数据。旧档案存在正文与页面日期可疑错配：一个标为 2005-02-16 的页面正文出现 4 月的复牌事实；不会用该页面日期反推生效日。正文出现未来日期仅标记复核，提前公布未来生效的正常通知也可能触发标记。

## 持续更新已经能运行

当前监管名单使用交易所公开接口，无需账户或 API Key。已完成多轮真实监管名单和补充行情状态采集，均成功；具体快照数见 `audit.json`。重复采集未产生虚假变化。当天为周日，没有观察到实际盘中状态变化；变化记录、失败保留与分页失败路径另有测试验证。

```sh
.venv/bin/vn-status watch --interval 300 --quotes --universe
```

每轮完成后等待五分钟再采集。交易所公开数据的发布延迟还未量化，所以五分钟是查询间隔，不是总延迟保证。进程完成有限轮次验证后已退出，未安装后台服务。

来源独立保存快照、观察时间和名单变化。失败保留旧快照，分页不完整不入库，名单突然减少超过 50% 进入复核。名单移除只代表来源记录消失，不自动判定恢复正常。

行情板和股票目录不能单独使用：HNX 监管名单有 1 只、UPCOM 有 91 只股票未出现在此次目录/行情板接口中。这可能涉及退出市场或其他来源差异，不能直接断定均为停牌。监管标签和交易标志存在差异，必须保留来源。HOSE 此次 32 只监管名单股票均在其股票目录中。

- [HOSE 状态字典](https://api.hsx.vn/l/api/v1/securities/status-list)：字典和每类记录已下载，包含部分生效日及原因。
- [HNX 当前名单和历史公告](https://www.hnx.vn/vi-vn/co-phieu-etfs/chung-khoan-ny-thong-tin.html)、[UPCOM 当前名单和历史公告](https://www.hnx.vn/vi-vn/co-phieu-etfs/chung-khoan-uc-thong-tin-ck.html)：完整分页下载成功。

- [Vietstock 事件日历](https://finance.vietstock.vn/lich-su-kien.htm?tab=2&languageid=2)：匿名浏览器和正常防伪会话的 curl 请求均成功；普通 requests 的 403 不代表数据不可抓。
- [FiinGroup HNX 日数据文档](https://datafeed.fiingroup.vn/api-datafeed-en/api-trading/stock/stock/hnx-stock-v2)：有 `SecurityTradingStatus`、`ListingStatus` 字段，但未实际取得 2000 年起状态数据，历史含义与覆盖仍未证明。
- [SSI 状态映射](https://guide.ssi.com.vn/ssi-products/fastconnect-data/data-mapping/securities-trading-status)：有实时交易状态；匿名 REST 请求要求认证，价格历史接口不能证明历史状态覆盖。
- [VietstockXLS 官方服务](https://dichvu.vietstock.vn/du-lieu-tai-chinh/vietstockxls---du-lieu-kinh-te-tai-chinh-chung-khoan-theo-yeu-cau)：介绍包含上市、退市、警示、控制、临时停牌等定制历史数据，可作为早期缺口的商业补充线索。尚未取得样例或确认 2000 年起状态覆盖，也没有购买或对外发送询价。

接下来需补早期档案，核对每只股票正式决定、生效/解除日与历史市场归属。商业来源必须用真实样例证明起始年份、退市股票覆盖及状态字段，营销资料不算验证。取得这些证据之前，不能生成声称从 2000 年起无缺口的回测状态表。

# Vietnam Quant

越南证券公告与事件数据采集项目。当前仓库保存原有采集脚本及数据快照，作为后续工程化重构的初始基线。

## 采集脚本

| 文件 | 当前用途 |
| --- | --- |
| `HOSE_最终1.py` | 使用 Selenium 驱动 Edge，拦截 HOSE 公告接口响应，按月抓取并合并去重。 |
| `HNX.py` | 抓取 HNX 历史公告表，解析分页表格并分批保存。 |
| `爬公告BCG.py` | 抓取 Vietstock 单只股票的分红发行、上市退市等事件；当前代码中指定的股票为 VNL。 |
| `爬所有公告cafeF.py` | 读取股票代码列表，从 CafeF 批量抓取公告日期、标题和链接。 |

## 数据快照

| 文件 | 内容 |
| --- | --- |
| `hnx_market_supervision_history_full.csv` | HNX 历史公告表快照。 |
| `hose_co_phieu_20260901_20261003.csv` | HOSE 公告快照，包含公告标识、标题、代码、日期时间及详情链接等字段。 |
| `hose_announcements.zip` | 按股票代码保存的 CSV，包含原始版与填充 `status` 字段的 updated 版；状态编码定义尚未记录。 |

## 当前状态

四个脚本相互独立，包含 Windows 本地路径和外部输入依赖，尚未形成统一配置、运行入口与依赖管理。仓库初始化保留原文件内容与路径，现有脚本和数据仍待重构。

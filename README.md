# Vietnam Quant｜越南股票每日状态

每天更新越南股票的详细状态，帮助量化研究识别警告、受控、交易限制和停牌等情况。

覆盖 **HOSE、HNX、UPCOM** 三个市场的当前股票。无需注册数据账户或申请 API Key，
支持 **Windows 和 macOS 双击运行**。

## 你会得到什么

- **一张状态表**：每只股票一行，包含交易日、市场、股票代码，以及五项来源状态。
- **完整保留的历史结果**：每次更新单独保存，同一天多次运行也不会覆盖。
- **明确的更新结果**：告诉你数据所属交易日、股票数量，以及是否有需要检查的问题。
- **失败保护**：新一轮失败或未通过检查时，不替换上一份可用结果。

状态包括监管状态、SSI 交易状态、DNSE 交易方式、DNSE 证券交易状态及停牌标志。
表内保留来源代码，不自行增加判断或推导标签。各列含义见[状态说明](docs/status-schema.md)。

## 开始使用

1. 将整个项目文件夹保存到电脑，先解压，再运行。
2. 安装 [Python 3.10 或更高版本](https://www.python.org/downloads/)。Windows 安装时勾选 **Add Python to PATH**。
3. 按你的系统双击对应文件：

| 系统 | 启动文件 |
| --- | --- |
| Windows | `更新股票状态.bat` |
| macOS | `更新股票状态.command` |

首次运行会自动准备所需组件，需要联网。后续运行直接开始更新。
等待窗口显示完成或失败信息，再关闭窗口；通常需要数分钟，网站响应较慢时会更久。

## 去哪里找结果

最近一次通过检查的表格在：

**`outputs/current-status/latest/status.csv`**

可以用 Excel、WPS 或数据分析工具打开。同一文件夹的 `result.txt` 会告诉你数据日期、
股票数量和提示信息。

以前的每一轮结果都保存在 **`outputs/current-status/runs/`**，按运行时间区分。
`latest` 是便于取用的副本；旧结果会一直保留，不自动清理。

## 如果更新失败

窗口会显示原因和本轮记录的位置。原来的 `latest` 会保留，但它可能已经不是最新日期，
**请先看表中的交易日，不要仅凭文件夹名称判断数据是否新鲜。**

- 网络失败：检查网络，稍后重新双击运行。
- 提示已有更新运行：等待前一轮结束，不必同时打开多个窗口。
- 无法替换结果：关闭 Excel/WPS 中打开的结果文件后重试。
- 提示数据需要检查：到本轮目录查看 `result.txt` 和问题报告，保留原始值，不把缺失当成正常。
- macOS 无法直接打开启动文件：查看[使用帮助](docs/usage.md)。

## 数据边界

数据来自 SSI、DNSE 的公开行情服务，并默认核对交易所股票目录。来源可能有延迟，
周末或节假日通常显示此前交易日的数据。更新成功表示程序检查通过，不保证来源没有
遗漏或错误，也不表示取得了所有监管措施的生效时间。

本工具用于当前状态采集；从你开始使用起逐次留存，不提供此前完整历史状态。
当前采用手动一键更新，不会自行创建系统定时任务。

更多操作见[使用帮助](docs/usage.md)。

# Vietnam Quant｜越南股票每日状态

每天更新越南股票的详细状态，帮助量化研究识别警告、受控、交易限制和停牌等情况。

覆盖 **HOSE、HNX、UPCOM** 三个市场的当前股票。无需注册数据账户或申请 API Key，
支持 **Windows 和 macOS 双击运行**。

## 你会得到什么

- **一张状态表**：每只股票一行，包含交易日、市场、股票代码，以及五项来源状态。
- **完整保留的历史结果**：每次更新单独保存，同一天多次运行也不会覆盖。
- **明确的更新结果**：告诉你数据所属交易日、股票数量，以及是否有需要检查的问题。
- **失败保护**：新一轮失败或未通过检查时，不替换上一份可用结果。

状态包括监管状态、SSI 交易状态、DNSE 交易方式、DNSE 证券交易状态及停牌标志。
表内保留来源代码，不自行增加判断或推导标签。各列含义见[状态说明](docs/status-schema.md)。

## 运行结果示例

下面摘自一次真实运行生成的 `status.csv`，保留导出文件的八列及原始值。
该次结果共 **1,519 只股票**，数据所属交易日为 **2026-10-23**；这里只展示六行，
用于说明结果样式，不代表这些股票现在的状态。

| trade_date | market | symbol | ssi_admin_status | ssi_trading_status | dnse_trading_method_status | dnse_trading_sanction_status | dnse_security_status |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 2026-10-23 | HOSE | AAA | NRM | N | 1 | 1 | 2 |
| 2026-10-23 | HOSE | APG | WFR | N | 1 | 1 | 2 |
| 2026-10-23 | HOSE | ABS | CTR | N | 1 | 1 | 2 |
| 2026-10-23 | HNX | BNA | CTR | S | 1 | 2 | 1 |
| 2026-10-23 | UPCOM | ACM | RES | RT | 1 | 1 | 2 |
| 2026-10-23 | UPCOM | ANI | NRM | ST | 5 | 1 | 2 |

例如，监管列中的 `WFR` 表示财务报告相关警告，`CTR` 表示受控；SSI 交易状态中的
`S` 表示暂停交易。因此，示例中的 APG 是警告状态，BNA 同时呈现受控和暂停交易。
各列分别表达不同信息，具体含义和取值如下。

## 如何读这张表

`ssi_` 和 `dnse_` 分别表示数据来自 SSI、DNSE。表中保留来源的代码或数字，
下面的中文说明用于帮助阅读，不会增加到导出表中。

| 列名 | 具体含义 | 取值形式 |
| --- | --- | --- |
| `trade_date` | 来源数据所属交易日，不是抓取日期，也不是状态开始生效的日期 | `YYYY-MM-DD`，如 `2026-10-23` |
| `market` | 股票所属市场 | `HOSE`、`HNX`、`UPCOM` |
| `symbol` | 股票代码；与市场一起识别一只股票 | 如 `AAA`、`BNA`、`ACM` |
| `ssi_admin_status` | 监管分类：是否受到警告、受控或交易限制等措施 | 字符串代码，见下表 |
| `ssi_trading_status` | SSI 给出的综合交易状态：正常、限制、暂停、新上市等 | 字符串代码，见下表 |
| `dnse_trading_method_status` | 交易方式分类：常规交易或新上市、暂停后等特殊方式 | 数字 `0`—`5`，见下表 |
| `dnse_trading_sanction_status` | DNSE 给出的证券交易状态：正常、暂停、因转板退市、因限制停止交易等 | 数字 `0`—`4`，见下表 |
| `dnse_security_status` | DNSE 的停牌标志原值；数字与停牌含义的正式映射尚未确认 | 已观测到 `1`、`2`；`0` 按未明确处理 |

以下列出当前已整理的取值，不保证来源今后不会新增代码。

### 监管状态：`ssi_admin_status`

| 取值 | 含义 |
| --- | --- |
| `NRM` | 正常监管分类 |
| `WFR` | 财务报告相关警告 |
| `WID` | 信息披露相关警告 |
| `WOV` | 其他违规警告 |
| `CTR` | 受控 |
| `RES` | 限制交易 |
| `C&R` | 同时受控且限制交易 |

### SSI 综合交易状态：`ssi_trading_status`

| 取值 | 含义 |
| --- | --- |
| `N` | 正常交易 |
| `RT`、`TFR` | 限制交易 |
| `S` | 暂停交易 |
| `D` | 退市 |
| `NL` | 新上市 |
| `ST` | 特殊交易 |

### DNSE 交易方式：`dnse_trading_method_status`

| 取值 | 含义 |
| --- | --- |
| `0` | 未指定 |
| `1` | 常规交易方式（NRM） |
| `2` | 新上市特殊涨跌幅（NWE） |
| `3` | 新上市常规涨跌幅（NWN） |
| `4` | 暂停后的特殊交易方式（SLS）；不能仅凭此值判断已经复牌 |
| `5` | 特殊交易（SNE） |

### DNSE 证券交易状态：`dnse_trading_sanction_status`

| 取值 | 含义 |
| --- | --- |
| `0` | 未指定 |
| `1` | 正常（NRM） |
| `2` | 暂停（SUS） |
| `3` | 因转板退市（DTL） |
| `4` | 因限制停止交易（TFR） |

这一列与 SSI 综合交易状态的分类口径不同，不能逐值互换。例如示例中的 ACM，
SSI 为限制交易 `RT`，DNSE 这一列为 `1`；两个原值都会保留，不能据此认定它“完全正常”。

### DNSE 停牌标志：`dnse_security_status`

| 取值 | 当前能确认的情况 |
| --- | --- |
| `0` | 本项目按未明确状态处理，不能判为正常 |
| `1` | 已观测到的原始数字；与停牌含义的正式数字映射尚待确认 |
| `2` | 已观测到的原始数字；与停牌含义的正式数字映射尚待确认 |

因此，目前不把 `1`、`2` 直接翻译为“停牌／未停牌”，也不建议单独用这一列作交易判断。

**“正常”只描述所在列，不代表其他列也正常。** 警告或受控的股票仍可能处于正常交易状态。
空白、`null`、未指定值及未知代码都不能当作正常；出现这些情况时应查看本轮问题报告。
代码含义的来源依据、不同接口的差别及未确认项见[状态说明](docs/status-schema.md)。

## 开始使用

1. 将整个项目文件夹保存到电脑，先解压，再运行。
2. 安装 [Python 3.10 或更高版本](https://www.python.org/downloads/)。Windows 安装时勾选 **Add Python to PATH**。
3. 按你的系统双击对应文件：

| 系统 | 启动文件 |
| --- | --- |
| Windows | `更新股票状态.bat` |
| macOS | `更新股票状态.command` |

首次运行会自动准备所需组件，需要联网。后续运行直接开始更新。
等待窗口显示完成或失败信息，再关闭窗口；通常需要数分钟，网站响应较慢时会更久。

## 去哪里找结果

最近一次通过检查的表格在：

**`outputs/current-status/latest/status.csv`**

可以用 Excel、WPS 或数据分析工具打开。同一文件夹的 `result.txt` 会告诉你数据日期、
股票数量和提示信息。

以前的每一轮结果都保存在 **`outputs/current-status/runs/`**，按运行时间区分。
`latest` 是便于取用的副本；旧结果会一直保留，不自动清理。

## 如果更新失败

窗口会显示原因和本轮记录的位置。原来的 `latest` 会保留，但它可能已经不是最新日期，
**请先看表中的交易日，不要仅凭文件夹名称判断数据是否新鲜。**

- 网络失败：检查网络，稍后重新双击运行。
- 提示已有更新运行：等待前一轮结束，不必同时打开多个窗口。
- 无法替换结果：关闭 Excel/WPS 中打开的结果文件后重试。
- 提示数据需要检查：到本轮目录查看 `result.txt` 和问题报告，保留原始值，不把缺失当成正常。
- macOS 无法直接打开启动文件：查看[使用帮助](docs/usage.md)。

## 数据边界

数据来自 SSI、DNSE 的公开行情服务，并默认核对交易所股票目录。来源可能有延迟，
周末或节假日通常显示此前交易日的数据。更新成功表示程序检查通过，不保证来源没有
遗漏或错误，也不表示取得了所有监管措施的生效时间。

本工具用于当前状态采集；从你开始使用起逐次留存，不提供此前完整历史状态。
当前采用手动一键更新，不会自行创建系统定时任务。

更多操作见[使用帮助](docs/usage.md)。
